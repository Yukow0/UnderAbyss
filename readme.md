## Overview

UnderAbyss is an ambitious Minecraft mod that aims to revolutionize underground exploration with new survival mechanics
and challenging environments. Face the dangers of toxic atmospheres and discover new ways to survive in the depths.

## Planned Features

- Filters for the Nether and The End
- A end game enchantment for the filters
- Stronger Mobs
